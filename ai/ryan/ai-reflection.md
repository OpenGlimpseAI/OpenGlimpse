Using AI was able to speed up my workflow alot more. I usually prefer back end development, and feel like
front end development is a bit more tedious and time consuming, but with AI I was able to speed up the process and get more done in a shorter amount of time. I think AI is a very useful tool for developers and can help a lot with productivity and efficiency. 
Especially when it comes to debugging and updating code, AI can be a great help in identifying issues and providing solutions. 

I also used the AI to help me collect logs, asked it how to sign up for the different cloud services and etc, which
helped save me alot of time. The AI was able to look at my codebase and give me extremely tailored instructions on what to
do, which I also found super helpful.

There were specific instances where I had to reject or modify the AIs output, there were a few times where
the AI would create files with code that already existed elsewhere, or tried to rewrite functioning code even
though it already worked. I always screened through the AI written code and vetted it properly, and rejected these contributions
in order ot ensure the codebase did not become overly bloated with repetitive code overtime, or broke
old code that worked. This thought me how to better prompt and direct the AI system on what files to 
review, and how to reduce this issue with prompting.

This taught me how AI can be a powerful productivity tool, but that it is important to use it wisely and not rely on it too heavily. It is important to always review and vet the AI's output, and to ensure that it aligns with the project's architecture and requirements. Overall, I think AI has been a valuable asset in my development process and has helped me to be more productive and efficient in my work.
